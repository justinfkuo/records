Records Database Specifications

This reference defines the exact columns and formatting rules used to maintain the USA Track & Field (USATF) records database. Record keepers typically maintain their records in Excel spreadsheets or CSV files and submit them to be merged into the master database and exported for upload to the USATF web servers.

Data Entry Guidelines & Notes

Important rules to ensure clean uploads to the master USATF records database.

Clean Whitespace & Punctuation

Remove leading or trailing spaces from all text fields. Check for stray punctuation—for example, a mark of 5:21:21. has a trailing period that must be removed.

Track Relays

Set type to relay, distance medley relay, shuttle hurdles relay, or sprint medley relay. Enter the total relay distance (e.g., 3200 for 4×800m; 4000 for DMR). Put the team name in affiliation and members in the relay leg fields. Open track relays may have both a USA National Team record and a club relay record for the same distance.

Road Relays (Ekiden)

Set type to relay, Implement height/weight to 5-leg or 6-leg, distance to 42.195, and units to km. Enter the team name in affiliation and runners in the relay leg fields.

Women's Only Races

Indicate women-only races with yes in column 40 (women's only race). For mixed-gender races, use no or leave blank. Road events may have two records per distance (women-only and mixed), whereas track events 5000m and up have a single record regardless of mixed genders.

State & Country Separation

Keep event city, event state, and event country separate (e.g., for Ottawa, CAN, enter Ottawa in city and CA in country). Whenever a 2-letter US state is entered in home state or event state, set the corresponding country field to US. See the Country Codes page for ISO 3166 codes.

Duplicate Records Across Categories

Create separate duplicate rows when one mark qualifies for multiple categories—for example, an Open record that is also an All-Comers record, or a 40-year-old athlete who sets both an open and a 40-44 record.

File Naming & Submissions

When submitting spreadsheets, include the date in the filename (e.g., 2026-11-21-LDR-records.xlsx or 2026-11-21-mastersRW.csv) to avoid version confusion. For large Excel files sent via email, compressing them as .zip or .7z significantly reduces attachment size.
